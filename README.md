# Campus Club Event Management System

## Project Overview

This project focuses on the design and development of a Campus Club Event Management System. The system helps student organizations manage events, track RSVPs, and monitor attendance.

## Purpose

Student organizations often use spreadsheets and messaging apps to manage events, which leads to inefficiencies and poor tracking. This system provides a centralized solution for event management.

## Key Features

* Create and manage events
* RSVP to events
* Track attendance
* Generate reports

## Technologies Used

* Database: SQL
* Version Control: GitHub
* Modeling Tools: Lucidchart or Visio
* Containerization: Docker

## Deliverable 4 Focus

This repository will contain:

* Entity Relationship Diagram (ERD)
* SQL script (tables + insert data)
* Architecture diagrams and matrices
* System design documentation
